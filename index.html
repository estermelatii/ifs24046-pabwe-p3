Tentang LinkVault

LinkVault dibuat sebagai studi kasus Praktikum 3 mata kuliah PABWE — proyek satu halaman berbasis JavaScript murni tanpa backend. Tiga fitur di atas (Catatan Keuangan, Manajemen Tautan, dan Kuis Interaktif) menunjukkan manipulasi DOM, penanganan event, dan penyimpanan data lewat localStorage agar tetap tersimpan meski browser ditutup.
